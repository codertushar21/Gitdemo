# 💰 Salary Tax Calculator (Python)

A Python-based salary tax calculator that computes the **tax deducted** and the **final in-hand salary** based on different tax percentages applied to various salary ranges.

## 📌 Features

- Calculate tax deduction for different salary amounts.
- Supports multiple tax percentage slabs.
- Displays:
  - Gross Salary
  - Applicable Tax Rate
  - Tax Deducted
  - Final In-Hand Salary
- Simple command-line interface.
- Beginner-friendly Python project.

## 🛠️ Technologies Used

- Python 3

## 🚀 How It Works

1. Enter the employee's salary.
2. The program determines the applicable tax percentage based on predefined salary ranges.
3. It calculates:
   - Tax Deduction
   - Net (In-Hand) Salary
4. Displays the results instantly.

## 📊 Example

```
Enter Salary: 60000

Applicable Tax Rate: 20%
Tax Deducted: 12000
Final In-Hand Salary: 48000
```

## 🧮 Formula Used

```
Tax Deducted = Salary × (Tax Rate / 100)

Net Salary = Salary − Tax Deducted
```
